## 修复 移动端主界面「出库」按钮在小屏/横屏不可见
- 文件：`mobile-android/app/src/main/java/com/dip/material/ui/home/HomeScreen.kt`
- 问题根因：主界面 7 个功能卡片用固定「每行 3 个 Row」排在**非滚动**的 Column 里，内容在小屏/横屏溢出，最后一行（出库卡片）被裁切且无法滚动到。
- 修复：将固定 3 列 Row 改为响应式的 `LazyVerticalGrid(columns = GridCells.Adaptive(minSize = 100.dp))`，`Modifier.fillMaxWidth().weight(1f)` 占满剩余空间并内部纵向滚动；卡片改为 `aspectRatio(1f)` 等宽等高。列数随屏宽自适应，出库按钮在所有尺寸下始终可滚动到达。
- 验证：`./gradlew.bat :app:compileDebugKotlin --offline` → BUILD SUCCESSFUL。
- 注意：`Icons.Default.ExitToApp` 在该 material-icons 版本下 `AutoMirrored.Filled.ExitToApp` 不存在（编译报错），故保留原 `Icons.Default.ExitToApp`（仅 deprecation 警告，可编译）。

## 环境：AAPT2 打包失败（缺 UCRT）
- 现象：`processDebugResources` FAILED，报 `AAPT2 ... Daemon startup failed / Please check if you installed the Windows Universal C Runtime`。
- 根因：本机 Windows 缺 Universal C Runtime，aapt2.exe 起不来；与代码无关（compileDebugKotlin 已 SUCCESSFUL）。
- 解决：安装 Visual C++ Redistributable x64（https://aka.ms/vs/17/release/vc_redist.x64.exe，含 UCRT），管理员运行，重开 PowerShell 后 `.\gradlew.bat assembleDebug`。
