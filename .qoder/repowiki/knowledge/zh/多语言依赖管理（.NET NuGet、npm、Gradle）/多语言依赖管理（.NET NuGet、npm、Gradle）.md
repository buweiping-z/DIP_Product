本仓库为全栈项目，包含 C# ASP.NET Core 后端、React 前端与 Android PDA 客户端，各子模块使用各自语言的包管理器进行依赖声明与管理。

**1. .NET 后端（dip-system/api）**
- 使用 `.csproj` 文件通过 `<PackageReference>` 声明 NuGet 包依赖，目标框架为 `net8.0`。
- 关键依赖包括：Pomelo.EntityFrameworkCore.MySql（MySQL ORM）、Swashbuckle.AspNetCore（API 文档）、QuestPDF（PDF 生成）、BCrypt.Net-Next（密码加密）、ClosedXML（Excel 处理）等。
- 未使用 `packages.config` 或 `global.json`，也未见 `nuget.config` 私有源配置，默认使用 nuget.org。
- 构建产物目录 `publish/` 中包含了所有编译后的 DLL，属于自包含发布模式。

**2. React 前端（dip-system/frontend-web）**
- 使用 `package.json` 声明 npm 依赖，分为 `dependencies` 和 `devDependencies` 两类。
- 运行时依赖：axios、react、react-dom、react-router-dom、jsbarcode、lucide-react。
- 开发依赖：vite、typescript、tailwindcss、postcss、autoprefixer 及类型定义包。
- 使用 `package-lock.json` 锁定依赖版本，lockfileVersion 为 3。
- 未使用 yarn.lock 或 pnpm-lock.yaml，仅使用 npm 原生锁文件。
- 未发现 `.npmrc` 或私有 npm 源配置。

**3. Android 移动端（mobile-android）**
- 使用 Gradle Kotlin DSL (`build.gradle.kts`) 声明依赖，采用 BOM（Bill of Materials）管理 Compose 相关依赖版本一致性。
- 关键依赖：Retrofit + Gson（网络请求）、Koin（依赖注入）、CameraX（相机）、ML Kit Barcode Scanning（条码扫描）、DataStore（本地存储）等。
- `settings.gradle.kts` 中通过 `dependencyResolutionManagement` 统一配置仓库源：google()、mavenCentral()，并启用 `RepositoriesMode.FAIL_ON_PROJECT_REPOS` 禁止子项目自定义仓库。
- 未使用 `gradle.properties` 中的私有源配置，也未见 `local.properties` 中的 SDK 路径硬编码。

**4. 共享资源与发布**
- `dip-system-portable/` 目录包含已发布的可执行文件和依赖 DLL，用于便携部署。
- 字体文件（LatoFont、simhei.ttf）直接随应用分发。
- 未发现统一的依赖更新脚本或自动化升级工具。

**5. 约束与约定**
- Android 模块强制使用集中式仓库配置，禁止在子项目中单独声明仓库源。
- 前端使用语义化版本范围（如 `^1.7.3`），允许小版本自动升级。
- .NET 项目使用精确版本号（如 `8.0.0`），避免意外升级。
- 未发现私有制品库（如 Nexus、Artifactory）或代理配置。
