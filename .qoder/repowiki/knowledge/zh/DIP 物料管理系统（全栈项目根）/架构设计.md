本仓库采用前后端分离 + 移动端的多端架构：`dip-system/api/` 提供 C# ASP.NET Core 8.0 REST API（EF Core + MySQL），`dip-system/frontend-web/` 通过 Vite 代理访问 8800 端口，`mobile-android/` 作为 PDA 扫码客户端；三者共享同一套业务领域模型（订单/备料/上线/出库/替代料/库存批次等），通过 HTTP JSON 通信。根目录的 `CLAUDE.md` 记录完整迁移履历与避坑经验，`readme.txt` 与 `xgyj.txt` 为架构设计审查意见，`产品BOM导入模板.xlsx` 与 `库存导入模板.xlsx` 是业务数据导入标准格式，构成跨端的统一数据契约。
