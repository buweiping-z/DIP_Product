- 每个业务功能以独立包组织，包内成对出现 `*Screen.kt`（Compose 界面）与 `*ViewModel.kt`（状态管理），通过 `viewModel()` 工厂注入 ViewModel。
- 导航统一在 `MainActivity` 的 `AppNavHost` 中以字符串路由注册，页面间通过 lambda 回调（如 `onNavigateToXxx`、`onBack`）传递跳转意图。
- 网络请求统一经 `RetrofitClient.getApiService(context)` 获取，baseUrl 为类变量可动态修改，OkHttp 通过 `WifiSocketFactory` 绑定 WiFi Network 确保双网不串流。
- 认证采用 Bearer Token 模式，`TokenHolder` 持久化 access_token 与 refresh_token，`AuthInterceptor` 附加 Authorization 头，`TokenAuthenticator` 在 401 时自动刷新并重试。
- 扫码输入通过 `ScanBroadcastReceiver` 接收 SEUIC 广播后统一经 `ScanBus.emit` 发射，由 ScanBus 单例负责去重，避免重复处理同一条码。
- UI 主题集中在 `ui.theme` 包（Color.kt、Type.kt、Theme.kt），所有屏幕通过 `DIPTheme` 包裹并使用 Material3 组件与 `MaterialTheme.colorScheme` 配色。
