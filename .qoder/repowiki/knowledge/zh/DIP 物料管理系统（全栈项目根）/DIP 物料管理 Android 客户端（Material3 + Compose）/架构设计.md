采用标准的 MVVM + Compose 分层：
- 入口层：`DIPApplication` 负责全局初始化（扫码音效、Token 缓存、WiFi 网络回调），`MainActivity` 通过 `NavHost` 集中声明所有页面路由（login/home/shelving/prep/refill/return/online/substitute/outbound/changeover/callmaterial）。
- UI 层：每个业务模块独立包（如 `ui.home`、`ui.shelving` 等），每个包内包含 `*Screen.kt`（Compose 界面）和 `*ViewModel.kt`（状态与业务逻辑），通过 `viewModel()` 工厂注入。
- 数据层：`data.network` 下以 Retrofit + OkHttp 为核心，`RetrofitClient` 单例持有 `ApiService`，并通过自定义 `WifiSocketFactory` 强制绑定 WiFi Network，避免双网场景请求走错通道；`AuthInterceptor` 与 `TokenAuthenticator` 协作实现 Bearer Token 自动刷新。
- 工具层：`utils` 封装扫码广播接收器（SEUIC Cruise 模式）、扫码总线（ScanBus 去重）、偏好存储（PreferencesManager）、声音反馈（ScanSoundManager）等横切能力。
- 依赖方向严格单向：UI → ViewModel → data/network → Retrofit/OkHttp，无反向依赖。
